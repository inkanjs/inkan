# 0.11.0: the studio, and the same speed

0.11 turns the inspector into the studio and adds `protect`. Both live in the built-in pages,
which are answered before any route. A first bench of 0.11 against v0.10.0 (runs
43412176009, 43412181386, 43412187406) had 0.11 behind in all three runs, 89.6 against 91.1
as the median: by 0.4 points twice and 1.6 once, mostly in a single scenario. The one change
on the path of an ordinary request was that a request that is not GET or HEAD no longer left
`builtin()` at once. #44 brought that early return back, for when the studio is off, so a
request in production takes the same path as in 0.10. These are the runs after it.

## On the GitHub runner, release gate

2026-11-13, `main` at #44 against v0.10.0 as `inkan-base`: runs 43422242096, 43422258996,
